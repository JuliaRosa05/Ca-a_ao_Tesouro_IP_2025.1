💎 **Caça ao Tesouro (Treasure Hunt) - Multiplayer Local**
Projeto de jogo de Caça ao Tesouro para dois jogadores, desenvolvido em Python utilizando a biblioteca Pygame. O objetivo é encontrar todos os tesouros no tabuleiro antes do adversário, acumulando a maior pontuação para vencer a partida.

🎯 **Funcionalidades e Objetivos**
O jogo é uma adaptação de lógica de revelação de tabuleiro com um sistema competitivo de turnos e pontuação.

Dois Jogadores: O jogo é alternado entre o Jogador 1 e o Jogador 2 a cada clique de revelação.

Tabuleiro Dinâmico: O tabuleiro é gerado proceduralmente a cada rodada, com posições aleatórias para tesouros e buracos.

**🏅 Sistema de Pontuação**
A pontuação é crucial para determinar o vencedor:
Tesouro (T)	+100 Pontos	Adiciona pontos ao jogador atual.
Buraco (B)	-50 Pontos	Subtrai pontos do jogador atual. Nota: A pontuação de um jogador nunca fica negativa

**💡 Regras e Dicas**
Dicas Numéricas: Os quadrados com números funcionam como dicas, indicando a quantidade exata de tesouros presentes nos quadrados vizinhos (adjacentes e diagonais).

Condição de Vitória: O jogo se encerra quando todos os tesouros no tabuleiro são revelados. O vencedor é o jogador que possuir a maior pontuação.

**💻 Tecnologias e Estrutura**
Este projeto foi desenvolvido no âmbito da disciplina de Introdução à Programação, aplicando os seguintes conceitos e ferramentas:

Linguagem: Python

Biblioteca Gráfica: Pygame (Utilizada para renderização da interface, tabuleiro e gerenciamento de eventos).

Estrutura de Código: Programação Orientada a Objetos (POO), utilizando classes para organizar a lógica do jogo
